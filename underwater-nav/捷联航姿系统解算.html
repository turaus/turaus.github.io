                • 航姿系统解算原理

                1. 概述

                航向姿态参考系统（ Attitude and Heading Reference System ，AHRS）简称为“ 航姿系统” 或“航姿仪”， 是用于指示载体相对航姿基准的航向与水平姿态信息的设备。

                捷联航姿参考系统（Strapdown Attitude and Heading Reference System）是一种能够提供被测运动体的航向、水平姿态等信息的捷联式航向姿态参考系统。包括陀螺捷联航姿系统和电磁罗经。

                Note

                名词解释

                航姿基准：导航坐标系的三个方向。

                捷联：与载体固连或直接联结，两者间没有相对角运动。在导航中特指 IMU 与载体固连。

                航姿系统：是罗经和垂直参考单元的结合，运动状态下能自主稳定连续地提供姿态、航向的导航设备。

                • 罗经：运动状态下能自主稳定指北的导航设备，不明确要求罗经指示水平姿态。

                • 垂直参考单元（Vertical Reference Unit）：能自主稳定指示水平姿态的导航设备，可称为垂直陀螺仪、地平仪。有些VRU也可自主提供无参考标准的航向角，（启动时航向角一般为0°) 。

                2. 陀螺仪视运动

                2.1 基本知识

                坐标系定义：

                夹角定义

                1. 方位角 α：陀螺主轴 xg 与子午面的水平夹角，NWU 坐标系下规定偏西为正。表示陀螺主轴的指北偏差。

                2. 高度角 θ：陀螺主轴 xg 与 NWU 水平面的垂直夹角，NWU 坐标系下规定偏下为正。

                2.2 视运动规律（罗经效应——东升西降）

                基础设定：

                • 陀螺主轴初始水平指北。

                • 地球自转角速度 ωie 分解为水平分量 ω1=ωiecos⁡φ 和垂直分量 ω2=ωiesin⁡φ。（这里的 φ 表示纬度）

                推导过程：

                1. 水平偏移（方位角变化）：

                  由于 ω2 作用，陀螺主轴指北端以速度 v2=Hωiesin⁡φ 向东运动。

                2. 升降运动（高度角变化）：

                  当主轴有方位角偏差 α 时，ω1 在陀螺y轴分量为 ω1y=ω1sin⁡α，

                  产生虚力矩 M1，导致升降运动速度：

                  v1=Hω1sin⁡α=Hωiecos⁡ϕsin⁡α

                3. 罗经效应方向：

                  • 东升西降：东边上升（高度角增加），西边下降（高度角减小）。

                  • 北纬东偏，南纬西偏。

                参考：陀螺罗经视运动理解

                3. 航姿系统设计

                航姿系统设计思想：寻找相对静止的物理量

                3.1 重力摆式陀螺罗经

                Note

                重力摆式陀螺罗经用二自由度陀螺仪 G 跟踪 NWU 坐标系

                设初始时刻 G 动量矩 H 与北向 x 轴重合（初始对准），由于 G 具有定轴性，动量矩 H 拟可稳定指北，从而作为载体的航向基准。

                Important

                陀螺仪 G 相对于惯性系静止，而地球相对于惯性系有自转角速度 ωie ，而人在地球上观察 G ，所以人观测到的是陀螺仪相对于地球的速度，即 −ωie。

                地球自转角速度 ωie 分解为 ω1′ 和 ω2′ ， ω2=−ω2′ 对陀螺仪产生一个视在的力矩，在北半球使得主轴向东偏转， 产生一个负方位角 −α 。（北东南西）

                主轴向东偏转后，ω1′ 在垂直主轴方向上产生分量 w1′sin⁡α，陀螺仪视在运动与之相反，产生抬头趋势 （东升西降）

                θ˙=−ωiecos⁡L⋅sin⁡(−α)≈ωiecos⁡L⋅α

                自由陀螺仪不能指北的矛盾：

                • 主轴指北端相对导航坐标系水平面的升降运动

                • 主轴指北端相对导航坐标系北向的水平偏移运动(主要)

                解决方法：施加控制力矩使陀螺仪主轴发生进动，跟踪地球北向

                施加控制力矩的要求:

                • 自动产生，根据进动的需要，大小和方向都要合适

                • 应能随纬度的变化，自动的进行调整

                下重式罗经的灵敏部分是一个陀螺球，其重心低于几何中心（偏距 a）。当主轴（动量矩 H→）偏离水平面时，产生绕水平轴（yg 轴）的重力矩：

                My=mgsin⁡θa≈mgθa=Mθ

                在该控制力矩下，由赖柴尔定理可知，抬头的 θ （但是 θ 向下为正）能够使得主轴发生向西的进动（绕 zg 轴），则有：

                α˙ctrl=|H→×M→yH2|=−MHθ

                而地球自转引起的水平视运动满足（北半球向东转，所以为负的）：

                α˙visual=−ω2=−(−ωiesin⁡L)=ωiesin⁡L

                所以总方位角变化率：

                α˙=α˙ctrl+α˙visual=−MHθ−ω2

                变形得：

                H(α˙+ω2)=−Mθ

                又由罗经效应，得：

                θ˙=ω1α=ωiecos⁡L⋅α

                那么就可以得到方程组：

                {H(α˙+ω2)=−Mθθ˙−ω1α=0

                从赖柴尔定理的角度来理解：

                直接看陀螺仪主轴相对于惯性空间的“方位角变化率”，也可列出方程

                • 无阻尼时主轴做等幅椭圆摆动。

                • 需阻尼才能稳定指北。
