                  • 总结

                      • 推导核心是：用一组完备正交基对随机向量进行展开，取有限项近似，以均方误差最小为准则确定最优基，该基即为自相关矩阵的特征向量。

                      1. K-L 展开与截断近似

                      设{X}是 n 维随机模式向量 X 的集合。

                      选择一组完备归一化正交向量系 {uj}，可将 X 展开为：

                      X=∑j=1∞ajuj,aj=ujTX

                      若只取前 d 项来估计 X，记近似为：

                      X^=∑j=1dajuj

                      截断引起的均方误差为：

                      ξ=E[(X−X^)T(X−X^)]=E[∑j=d+1∞aj2]

                      2. 将误差表示为自相关矩阵的二次型

                      因为 aj=ujTX(X=∑j=1∞ajuj, ujTui=0)，所以：

                      ξ=E[∑j=d+1∞(ujTX)(XTuj)]=∑j=d+1∞ujTE[XXT]uj

                      记自相关矩阵为 R=E[XXT]（PPT中第48页明确使用总体自相关矩阵），则：

                      ξ=∑j=d+1∞ujTRuj

                      3. 优化问题：求使 ξ 最小的正交基

                      我们希望在正交约束 ujTuj=1 且 uiTuj=0 (i≠j) 下，选择 {ud+1,…} 使 ξ 最小。
                      这是一个条件极值问题，使用拉格朗日乘子法：

                      g(uj)=∑j=d+1∞ujTRuj−∑j=d+1∞λj(ujTuj−1)

                      对每个 uj 求导并令导数为零：

                      ∂g∂uj=2Ruj−2λjuj=0

                      即：

                      Ruj=λjuj,j=d+1,…,∞

                      因此，最优基向量 uj 是自相关矩阵 R 的特征向量，λj 为对应的特征值。

                      4. 均方误差的最小值

                      将特征方程代入 ξ 表达式：

                      ξ=∑j=d+1∞ujT(λjuj)=∑j=d+1∞λj

                      Note

                      上式指的是丢弃的特征值，所以应该保留前 d 个大的特征值，使得丢弃的最小

                      为了使 ξ 最小，应保留特征值最大的前 d 个特征向量（因为舍弃的是小特征值对应的项），即：

                      λ1≥λ2≥⋯≥λd≥λd+1≥⋯

                      取前 d 个最大特征值对应的特征向量构成变换矩阵，截断误差即为后面小特征值之和。

                      5. K-L 变换的矩阵形式

                      令变换矩阵 Un×d=[u1,u2,…,ud]，其中 uj 是归一化特征向量

                      则对任意样本 X，K-L 变换为：

                      a=UTX

                      a 是 d 维向量，称为变换后的特征向量。 近似重构公式为：

                      X^=Ua

                      6. K-L 特征提取的具体步骤

                      1. 求总体自相关矩阵 对 N 个样本 {Xj}：

                        R≈1N∑j=1NXjXjT

                      2. 计算 R 的特征值和特征向量 得到 λ1≥λ2≥⋯≥λn 及对应特征向量 u1,…,un。

                      3. 选择前 d 个特征向量 构造变换矩阵 U=[u1,…,ud]。

                      4. 对每个样本进行变换 X∗=UTX，得到 d 维特征向量。

                      7. 不同散布矩阵的 K-L 变换

                      PPT指出，K-L 变换中的 R 可替换为其他散布矩阵，以适应不同分类目标：

                      • 类内散布矩阵 Sw：突出类内紧凑性

                      • 类间散布矩阵 Sb：突出类间分离性

                      • 总体散布矩阵 St=Sb+Sw：兼顾两者

                      实际应用时可根据需要选择。

                      8. 与 PCA 的关系

                      K-L变换（Karhunen-Loève Transform），又称主成分分析（PCA）在离散情况下的实现。

                      区别在于：经典 PCA 使用 协方差矩阵（减去均值后的二阶统计量），而 K-L 变换中使用 自相关矩阵（未减均值）。若数据已零均值化，两者等价。

                      总结

                      K-L变换在均方误差最小的意义下，用自相关矩阵的特征向量作为正交基，对原向量进行线性变换，得到一组互不相关且方差递减的新特征。截断后保留大特征值对应的分量，可在压缩维数的同时最大程度保留信息。
